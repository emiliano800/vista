# cu-eval reports

One `<set>-<revision>.json` + `.md` per run of `scripts/cu_eval.py run <set>`, generated, not
committed (see `.gitignore`). Columns: locate accuracy, frame/move coverage, verified rate,
rejudged, recovery used, leakage failures, ambiguous locates; benchmark (recordings) and smoke
(synthetic) reported separately; milestone 1 / 2 status underneath.
