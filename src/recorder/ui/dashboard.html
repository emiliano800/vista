How it works

  • The agent may only perform a short list of actions (open a page, click a control it was shown, type a value from the approved inputs, press a key, read a table, take a screenshot) — never run scripts or commands.
  • Every step is checked on this computer against the session's limits before it runs, and written to a local log first.
  • Anything irreversible pauses the run until your workspace owner approves it. Sign-in, payment and private windows are refused.
  • Press Stop, or ⌘⇧Esc, at any time. Quitting the recorder stops the session.
  • Browser steps run in a separate Vista window with its own storage — none of your logins, cookies or history. Desktop steps (macOS only) act on the front window through its accessibility tree and need Accessibility permission. Anything this computer cannot perform is reported back so the run pauses for a person.
